**EXPERIMENT 3: GitHub Repository Creation and Push**

**Objective:**
To create a GitHub repository, push local code to remote, and clone a repository.

---

### **Execution Steps**

**Step 1: Create Repository on GitHub**

* Go to **GitHub**
* Click **New Repository**
* Enter repository name (e.g., `git-demo`)
* Select **Public/Private**
* Click **Create Repository**

---

### **Push Local Repository to GitHub**

**Step 2: Open Local Project**

```bash
cd git-demo
```

---

**Step 3: Add Remote Repository**

```bash
git remote add origin https://github.com/your-username/git-demo.git
```

* Links local repo to GitHub repo

---

**Step 4: Verify Remote**

```bash
git remote -v
```

---

**Step 5: Push Code to GitHub**

```bash
git push -u origin master
```

OR (if branch is main)

```bash
git push -u origin main
```

* Uploads code to GitHub
* `-u` sets upstream tracking

---

### **Clone Repository from GitHub**

**Step 6: Go to Parent Directory**

```bash
cd ..
```

---

**Step 7: Clone Repository**

```bash
git clone https://github.com/your-username/git-demo.git
```

* Downloads repository to local system

---

**Step 8: Navigate into Cloned Repo**

```bash
cd git-demo
```

---

**Step 9: Verify Files**

```bash
ls
```

---

### **Result**

Successfully created a GitHub repository, pushed local code, and cloned the repository.
