**EXPERIMENT 8: Jenkins Build Triggers (Polling & GitHub Webhook) – Windows**

---

## 🎯 **Objective**

To automatically trigger Jenkins builds when changes are made in a GitHub repository.

---

## 🧭 **Startup Guide (Windows System)**

### **Step 0: Ensure Prerequisites**

* Jenkins is running → http://localhost:8080
* Freestyle job (Exp 7) already working
* GitHub repo connected

---

## ⚙️ **Execution Steps**

---

# 🔹 **PART A: Poll SCM (Easy Method – Exam Friendly)**

### **Step 1: Open Jenkins Job**

* Go to **Jenkins Dashboard**
* Click your job → `demo-job`
* Click **Configure**

---

### **Step 2: Enable Poll SCM**

* Scroll to **Build Triggers**
* Tick:

```
Poll SCM
```

---

### **Step 3: Add Schedule**

```bash
H/2 * * * *
```

👉 Meaning:

* Checks GitHub every **2 minutes**

---

### **Step 4: Save**

* Click **Apply**
* Click **Save**

---

### **Step 5: Test Trigger**

* Make a change in your GitHub repo:

```bash
echo "change" >> test.txt
git add .
git commit -m "trigger build"
git push
```

---

### **Step 6: Observe Jenkins**

* Wait 1–2 minutes
* Build will trigger automatically

---

# 🔹 **PART B: GitHub Webhook (Real-Time Trigger)**

---

### **Step 1: Enable Webhook in Jenkins**

* Go to Job → **Configure**
* Under **Build Triggers**, tick:

```
GitHub hook trigger for GITScm polling
```

---

### **Step 2: Configure GitHub Webhook**

👉 Go to your GitHub repo:

* Click **Settings**
* Click **Webhooks**
* Click **Add webhook**

---

### **Step 3: Add Webhook URL**

```id="f2ib44"
http://<your-ip>:8080/github-webhook/
```

👉 For local system:

```id="nt0p8z"
http://localhost:8080/github-webhook/
```

⚠️ Note:

* For real working → use **ngrok/public IP**
* For exam → localhost is enough

---

### **Step 4: Select Events**

* Choose:

```
Just the push event
```

---

### **Step 5: Save Webhook**

---

### **Step 6: Test Webhook**

Make a change:

```bash
echo "webhook test" >> test2.txt
git add .
git commit -m "webhook trigger"
git push
```

---

### **Step 7: Observe Jenkins**

* Build starts **immediately (no delay)**

---

## 📌 **Important Commands Used**

```bash
git add .
git commit -m "message"
git push
```

---

## ⚠️ **Common Errors & Fix**

### ❌ Poll SCM not triggering

* Check cron syntax
* Wait at least 1–2 minutes

---

### ❌ Webhook not working

* Use correct URL
* Ensure Jenkins is running
* Check GitHub webhook delivery logs

---

## 🧠 **Key Points (Exam)**

* Poll SCM = periodic check
* Webhook = real-time trigger
* Cron format used in Poll SCM
* Webhook requires GitHub configuration

---

## 🎯 **Result**

Successfully configured Jenkins to automatically trigger builds using Poll SCM and GitHub Webhooks.
