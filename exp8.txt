EXPERIMENT 8: AES on Image (ECB vs CBC) + Image Steganography (OpenStego + Hex Editor)
🎯 Short Description
Perform AES encryption on an image using ECB and CBC modes and compare results.
Hide data inside an image and recover corrupted image using Hex Editor.
🔴 PART A: AES Encryption on Image (ECB vs CBC)
⚠️ IMPORTANT

👉 Convert image to BMP format (no compression)

Convert:
Open image in Paint
Save as:
image.bmp
⚙️ Step 1: ECB Encryption
openssl enc -aes-128-ecb -in image.bmp -out img_ecb.bmp -K 00112233445566778899aabbccddeeff -nosalt
⚙️ Step 2: CBC Encryption
openssl enc -aes-128-cbc -in image.bmp -out img_cbc.bmp -K 00112233445566778899aabbccddeeff -iv 0102030405060708090a0b0c0d0e0f10 -nosalt
⚙️ Step 3: Open Images
img_ecb.bmp
img_cbc.bmp
🔍 Observation
Mode	Output
ECB	Pattern visible
CBC	Fully random


PART B: Image Steganography + Hex Recovery
⚙️ Step 1: Create Secret File
notepad secret.txt

Write:

THIS IS SECRET
⚙️ Step 2: Hide Data (OpenStego)
Open OpenStego
Select Data Hiding → Embed
Inputs:
Message File → secret.txt
Cover File → cover.png
Output File → stego.png
Password → 1234
Click Hide Data
⚙️ Step 3: Extract Data
Open OpenStego → Extract
Select stego.png
Enter password → 1234
Extract
⚙️ Step 4: Corrupt Image (HxD)
Open stego.png in HxD
Modify first 8 bytes:
00 00 00 00 00 00 00 00
Save → Image will not open
⚙️ Step 5: Recover Image

Restore PNG header:

89 50 4E 47 0D 0A 1A 0A
Save → Image opens
