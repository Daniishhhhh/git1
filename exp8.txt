**EXPERIMENT 8: Build Triggers in Jenkins**

**Objective:**
To configure automatic build triggers in Jenkins (poll SCM / webhook).

---

### **Execution Steps**

### **Part A: Open Existing Job**

**Step 1: Open Jenkins Dashboard**

* Go to `http://localhost:8080`
* Select your job → `demo-job`

---

**Step 2: Configure Job**

* Click **Configure**

---

### **Part B: Configure Poll SCM (Auto Build)**

**Step 3: Enable Poll SCM**

* Scroll to **Build Triggers**
* Select **Poll SCM**

---

**Step 4: Add Schedule**

```bash
H/2 * * * *
```

* Checks GitHub repo every 2 minutes for changes

---

### **Part C: Connect GitHub Repository**

**Step 5: Add Source Code Management**

* Select **Git**
* Enter repository URL:

```
https://github.com/your-username/git-demo.git
```

---

### **Part D: Webhook Trigger (Alternative)**

**Step 6: Enable GitHub Hook Trigger**

* Select **GitHub hook trigger for GITScm polling**

---

**Step 7: Configure Webhook in GitHub**

* Go to GitHub repo → **Settings → Webhooks**
* Add webhook URL:

```
http://<your-ip>:8080/github-webhook/
```

---

### **Part E: Save and Test**

**Step 8: Save Configuration**

* Click **Save**

---

**Step 9: Test Trigger**

* Make a change in GitHub and push
* Jenkins automatically starts build

---

### **Result**

Successfully configured automatic build triggers using Poll SCM and GitHub Webhooks.
