EXPERIMENT 4: AES Encryption (ECB & CBC) + tcpdump Filters
🎯 Short Description
Perform AES encryption and decryption using ECB and CBC modes using OpenSSL.
Capture packets using tcpdump with protocol-based filters.
🔴 PART A: AES Encryption (ECB & CBC)
⚙️ Step 1: Create Plaintext File
notepad plain.txt

Write:

HELLO AES EXPERIMENT
⚙️ Step 2: AES Encryption (ECB Mode)
openssl enc -aes-128-ecb -in plain.txt -out ecb.enc -K 00112233445566778899aabbccddeeff -nosalt

👉 ECB = No IV required

⚙️ Step 3: AES Decryption (ECB)
openssl enc -aes-128-ecb -d -in ecb.enc -out ecb_dec.txt -K 00112233445566778899aabbccddeeff -nosalt
⚙️ Step 4: AES Encryption (CBC Mode)
openssl enc -aes-128-cbc -in plain.txt -out cbc.enc -K 00112233445566778899aabbccddeeff -iv 0102030405060708090a0b0c0d0e0f10 -nosalt

👉 CBC = IV required

⚙️ Step 5: AES Decryption (CBC)
openssl enc -aes-128-cbc -d -in cbc.enc -out cbc_dec.txt -K 00112233445566778899aabbccddeeff -iv 0102030405060708090a0b0c0d0e0f10 -nosalt
⚙️ Step 6: Verify Output
notepad ecb_dec.txt
notepad cbc_dec.txt
✅ Result (Part A)

AES encryption and decryption successfully performed using ECB and CBC modes.

🔴 PART B: tcpdump (Filters & Analysis)
⚙️ Step 1: Capture All Traffic
sudo tcpdump -i eth0
⚙️ Step 2: Capture Limited Packets
sudo tcpdump -i eth0 -c 10
⚙️ Step 3: Capture TCP Packets
sudo tcpdump -i eth0 tcp
⚙️ Step 4: Capture UDP Packets
sudo tcpdump -i eth0 udp
⚙️ Step 5: Capture DNS Traffic
sudo tcpdump -i eth0 port 53
⚙️ Step 6: Capture HTTP Traffic
sudo tcpdump -i eth0 port 80
⚙️ Step 7: Save Packets
sudo tcpdump -i eth0 -w capture.pcap
⚙️ Step 8: Read Saved File
tcpdump -r capture.pcap
⚙️ Step 9: Verbose Mode
sudo tcpdump -i eth0 -v
⚙️ Step 10: Incoming & Outgoing
sudo tcpdump -i eth0 inbound
sudo tcpdump -i eth0 outbound
