**EXPERIMENT 4: GitHub Collaboration using Pull Requests**

**Objective:**
To understand collaboration using fork, branch, pull request, and merge in GitHub.

---

### **Execution Steps**

### **Part A: Fork and Clone Repository**

**Step 1: Fork Repository**

* Go to original repository on GitHub
* Click **Fork** (creates a copy in your account)

---

**Step 2: Clone Forked Repository**

```bash
git clone https://github.com/your-username/git-demo.git
cd git-demo
```

---

### **Part B: Create Branch and Make Changes**

**Step 3: Create New Branch**

```bash
git checkout -b feature-branch
```

---

**Step 4: Modify File**

```bash
echo "Added new feature" >> file1.txt
```

---

**Step 5: Add and Commit Changes**

```bash
git add file1.txt
git commit -m "Added feature via branch"
```

---

### **Part C: Push Changes to GitHub**

**Step 6: Push Branch to GitHub**

```bash
git push origin feature-branch
```

---

### **Part D: Create Pull Request**

**Step 7: Open GitHub**

* Go to your forked repository
* Click **Compare & Pull Request**

---

**Step 8: Create Pull Request**

* Add title and description
* Click **Create Pull Request**

---

### **Part E: Merge Pull Request**

**Step 9: Review and Merge**

* Click **Merge Pull Request**
* Confirm merge

---

**Step 10: Update Local Repository**

```bash
git checkout main
git pull origin main
```

---

### **Result**

Successfully forked a repository, created a branch, pushed changes, and merged them using a pull request.
