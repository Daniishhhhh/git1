**EXPERIMENT 1: Introduction to Git and Local Repository Management**

**Objective:**
To create a local Git repository, add files, commit changes, and view history.

---

### **Execution Steps**

**Step 1: Open Terminal / Git Bash**
Open Git Bash or terminal in your working directory.

---

**Step 2: Create Project Directory**

```bash
mkdir git-demo
cd git-demo
```

---

**Step 3: Initialize Git Repository**

```bash
git init
```

* Initializes a new Git repository
* Creates hidden `.git` directory

---

**Step 4: Create a File**

```bash
echo "Hello DevOps Lab" > file1.txt
```

---

**Step 5: Check Repository Status**

```bash
git status
```

* Shows untracked files

---

**Step 6: Add File to Staging Area**

```bash
git add file1.txt
```

OR (add all files)

```bash
git add .
```

---

**Step 7: Commit the File**

```bash
git commit -m "Initial commit"
```

* Saves snapshot of project

---

**Step 8: Modify the File**

```bash
echo "Second line" >> file1.txt
```

---

**Step 9: Check Status Again**

```bash
git status
```

* Shows modified file

---

**Step 10: Add and Commit Changes**

```bash
git add file1.txt
git commit -m "Updated file1"
```

---

**Step 11: View Commit History**

```bash
git log
```

Short version:

```bash
git log --oneline
```

---

**Step 12: View Changes Between Commits**

```bash
git diff
```

---

### **Result**

Successfully created a Git repository, added files, committed changes, and viewed commit history.
