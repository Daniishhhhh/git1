🧪 EXPERIMENT 1: Steganography (Image) + Packet Capture (tcpdump)
🎯 Short Description
Hide secret text inside an image using steganography and recover corrupted image using hex editor.
Capture and analyze network packets using tcpdump with filters and file operations.
🔴 PART A: Image Steganography + Hex Recovery
⚙️ Steps
1. Create Secret File
notepad secret.txt

Write:

THIS IS A SECRET MESSAGE
2. Hide Data using OpenStego
Open OpenStego
Select Data Hiding → Embed
Input:
Message File → secret.txt
Cover File → cover.png
Output File → stego.png
Password → 1234
Click Hide Data
3. Extract Hidden Data
Open OpenStego → Extract
Select stego.png
Enter password 1234
Click Extract
4. Corrupt Image using HxD
Open stego.png in HxD
Go to offset 00000000
Replace first 8 bytes:
00 00 00 00 00 00 00 00
Save → Image will NOT open
5. Recover Image

Replace first 8 bytes with PNG header:

89 50 4E 47 0D 0A 1A 0A
Save → Image opens successfully
✅ Result (Part A)
Message hidden and extracted successfully
Corrupted image recovered using header restoration
🔴 PART B: Packet Capture using tcpdump
⚙️ Commands

Capture all packets
sudo tcpdump -i eth0

Capture 10 packets
sudo tcpdump -i eth0 -c 10

Capture TCP packets
sudo tcpdump -i eth0 tcp

Capture UDP packets
sudo tcpdump -i eth0 udp

Capture DNS traffic
sudo tcpdump -i eth0 port 53

Capture HTTP traffic
sudo tcpdump -i eth0 port 80

Save packets to file
sudo tcpdump -i eth0 -w capture.pcap

Read saved packets
tcpdump -r capture.pcap

Verbose output
sudo tcpdump -i eth0 -v

Incoming traffic
sudo tcpdump -i eth0 inbound

Outgoing traffic
sudo tcpdump -i eth0 outbound


Replace eth0 with your interface (Wi-Fi / wlan0 / Ethernet)
