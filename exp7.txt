**EXPERIMENT 7: Jenkins Freestyle Job**

**Objective:**
To create and execute a basic Jenkins Freestyle job.

---

### **Execution Steps**

### **Part A: Open Jenkins**

**Step 1: Start Jenkins**

```bash
sudo systemctl start jenkins
```

---

**Step 2: Open Jenkins Dashboard**

* Open browser → `http://localhost:8080`
* Login to Jenkins

---

### **Part B: Create Freestyle Job**

**Step 3: Create New Job**

* Click **New Item**
* Enter name → `demo-job`
* Select **Freestyle Project**
* Click **OK**

---

### **Part C: Configure Job**

**Step 4: Add Build Step**

* Scroll to **Build Section**
* Click **Add Build Step → Execute Shell**

---

**Step 5: Add Simple Command**

```bash
echo "Hello from Jenkins"
```

---

### **Part D: Build Job**

**Step 6: Save Job**

* Click **Save**

---

**Step 7: Build the Job**

* Click **Build Now**

---

### **Part E: View Output**

**Step 8: Check Console Output**

* Click build number → **Console Output**

---

### **Result**

Successfully created and executed a Jenkins Freestyle job and viewed the output.
