**EXPERIMENT 7: Jenkins Freestyle Job using Git + Maven (Windows Corrected)**

---

## 🎯 **Objective**

To create a Jenkins Freestyle Job that pulls a Maven project from GitHub and builds it successfully.

---

## 🧭 **Startup Guide (Windows System)**

### **Step 0: Start Jenkins**

```bat
cd C:\Program Files\Jenkins
java -jar jenkins.war
```

👉 Open browser:

```
http://localhost:8080
```

👉 Login

---

## ⚙️ **Execution Steps**

### **Step 1: Create New Job**

* Click **New Item**
* Name: `demo-job`
* Select **Freestyle Project**
* Click **OK**

---

### **Step 2: Configure Git Repository**

* Go to **Source Code Management**
* Select **Git**

👉 Repository URL:

```
https://github.com/Daniishhhhh/maven-project.git
```

---

### ⚠️ **IMPORTANT FIX (VERY IMPORTANT)**

👉 In **Branches to build**, change:

```
*/main
```

❌ Default is:

```
*/master   (WRONG)
```

---

### **Step 3: Add Build Step (Windows)**

👉 Build → Add Build Step → Execute Windows batch command

```bat
echo Building Maven Project
mvn clean package
```

---

### ⚠️ **CRITICAL CHECK (WHY YOUR ERROR CAME)**

👉 Ensure your GitHub repo has:

```
pom.xml  (MUST be in root)
```

Correct structure:

```
maven-project/
 ├── pom.xml
 ├── src/
```

---

### **Step 4: Save Job**

* Click **Apply**
* Click **Save**

---

### **Step 5: Build the Job**

* Click **Build Now**

---

### **Step 6: View Console Output**

* Click **Build #1**
* Click **Console Output**

---

## ✅ **Expected Output**

```
BUILD SUCCESS
```

---

## ❌ **Common Errors & Fix**

### ❌ Error: No POM file

👉 Fix:

* Set branch to `main`
* Ensure repo has `pom.xml` at root

---

### ❌ Error: mvn not recognized

```bat
"C:\Program Files\Apache\maven\bin\mvn.cmd" clean package
```

---

### ❌ Error: Wrong directory

👉 Jenkins automatically clones repo → no need to `cd`

---

## 📁 **Jenkins Workspace**

```
C:\ProgramData\Jenkins\.jenkins\workspace\demo-job
```

---

## 🧠 **Key Points (Exam)**

* Jenkins pulls code automatically from Git
* Must set correct branch (`main`)
* `pom.xml` must be in root
* Use Windows batch commands

---

## 🎯 **Result**

Successfully created a Jenkins Freestyle Job that pulls a Maven project from GitHub and builds it using Maven.
