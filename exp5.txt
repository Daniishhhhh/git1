**EXPERIMENT 5: Git Tagging and Release Management**

**Objective:**
To create, manage, and push Git tags for version control and releases.

---

### **Execution Steps**

### **Part A: Create and View Tags**

**Step 1: Open Existing Repository**

```bash
cd git-demo
```

---

**Step 2: View Existing Tags**

```bash
git tag
```

* Lists all tags (if any)

---

**Step 3: Create a Lightweight Tag**

```bash
git tag v1.0
```

* Creates a simple tag for current commit

---

**Step 4: Create an Annotated Tag**

```bash
git tag -a v1.1 -m "Version 1.1 release"
```

* Stores additional metadata (message, author, date)

---

**Step 5: View Tag Details**

```bash
git show v1.1
```

---

### **Part B: Push Tags to GitHub**

**Step 6: Push Specific Tag**

```bash
git push origin v1.0
```

---

**Step 7: Push All Tags**

```bash
git push origin --tags
```

---

### **Part C: Checkout Using Tags**

**Step 8: Checkout a Tag**

```bash
git checkout v1.0
```

* Moves to specific version (detached HEAD state)

---

### **Part D: Delete Tags**

**Step 9: Delete Local Tag**

```bash
git tag -d v1.0
```

---

**Step 10: Delete Tag from Remote**

```bash
git push origin --delete v1.0
```

---

### **Result**

Successfully created, viewed, pushed, and deleted Git tags for version control and release management.
