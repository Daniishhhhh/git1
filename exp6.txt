**EXPERIMENT 6: Maven Project Setup and Build**

**Objective:**
To create a Maven-based Java project, compile code, and generate a build artifact (JAR).

---

## 🧭 **Startup Guide (First Time on New System)**

**Where to work:**

* Open terminal
* Go to a working directory (example Desktop)

```bash
cd Desktop
```

---

## ⚙️ **Execution Steps**

### **Step 1: Create Maven Project (Using Archetype)**

```bash
mvn archetype:generate -DgroupId=com.example -DartifactId=maven-demo -DarchetypeArtifactId=maven-archetype-quickstart -DinteractiveMode=false
```

* Creates a complete Maven project structure

---

### **Step 2: Move into Project Directory**

```bash
cd maven-demo
```

---

### **Step 3: Project Structure Check**

```bash
ls
```

Expected folders:

* `src/main/java` → main code
* `src/test/java` → test code
* `pom.xml` → project configuration

---

### **Step 4: Open Project (Optional)**

* Open this folder in VS Code / IntelliJ

---

### **Step 5: Compile the Project**

```bash
mvn compile
```

* Compiles Java source code
* `.class` files generated in `target/`

---

### **Step 6: Run Default Test**

```bash
mvn test
```

* Executes test cases in `src/test/java`

---

### **Step 7: Package the Project (Create JAR)**

```bash
mvn package
```

* Generates `.jar` file in:

```
maven-demo/target/
```

---

### **Step 8: Run the JAR File**

```bash
java -cp target/maven-demo-1.0-SNAPSHOT.jar com.example.App
```

---

## 🧾 **Minimal Code (Auto Generated)**

### **Main Class**

Location:

```
src/main/java/com/example/App.java
```

(Default code is already present — no need to modify)

---

### **pom.xml (Important File)**

* Contains dependencies and build configuration
* Automatically created by Maven

---

```bash
mvn compile
mvn test
mvn package
```

---

## 🎯 **Result**

Successfully created a Maven project, compiled the code, executed tests, and generated a JAR file.
