**EXPERIMENT 6: Maven Project Setup and Build**

**Objective:**
To create a Maven project, configure dependencies, and build the project.

---

### **Execution Steps**

### **Part A: Create Maven Project**

**Step 1: Create Maven Project**

```bash
mvn archetype:generate -DgroupId=com.example -DartifactId=demo -DarchetypeArtifactId=maven-archetype-quickstart -DinteractiveMode=false
```

---

**Step 2: Navigate to Project Folder**

```bash
cd demo
```

---

### **Part B: Understand Project Structure**

* `src/main/java` → Application code
* `src/test/java` → Test code
* `pom.xml` → Project configuration

---

### **Part C: Build the Project**

**Step 3: Compile the Project**

```bash
mvn compile
```

---

**Step 4: Run Tests**

```bash
mvn test
```

---

**Step 5: Package the Project**

```bash
mvn package
```

* Generates `.jar` file in `target/`

---

### **Part D: Run the Application (Minimal Code)**

**Step 6: Edit Main Class**

```java
public class App {
    public static void main(String[] args) {
        System.out.println("Hello Maven");
    }
}
```

---

**Step 7: Run JAR File**

```bash
java -cp target/demo-1.0-SNAPSHOT.jar com.example.App
```

---

### **Result**

Successfully created a Maven project, compiled, tested, and packaged the application.
