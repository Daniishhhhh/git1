**EXPERIMENT 2: Working with Git Branches**

**Objective:**
To create branches, make changes, merge branches, and resolve conflicts.

---

### **Execution Steps**

**Step 1: Open Existing Repository**

```bash
cd git-demo
```

---

**Step 2: Check Current Branch**

```bash
git branch
```

* Shows current branch (`* master` or `main`)

---

**Step 3: Create a New Branch**

```bash
git branch feature1
```

* Creates a new branch named `feature1`

---

**Step 4: Switch to New Branch**

```bash
git checkout feature1
```

OR (modern command)

```bash
git switch feature1
```

---

**Step 5: Modify File in Branch**

```bash
echo "Feature1 changes" >> file1.txt
```

---

**Step 6: Add and Commit Changes**

```bash
git add file1.txt
git commit -m "Added feature1 changes"
```

---

**Step 7: Switch Back to Main Branch**

```bash
git checkout master
```

OR

```bash
git switch main
```

---

**Step 8: Modify File in Main Branch (to create conflict)**

```bash
echo "Main branch changes" >> file1.txt
```

---

**Step 9: Add and Commit Changes**

```bash
git add file1.txt
git commit -m "Updated in main branch"
```

---

**Step 10: Merge Feature Branch into Main**

```bash
git merge feature1
```

---

**Step 11: Resolve Merge Conflict (if occurs)**

* Open `file1.txt`
* Remove conflict markers:

```
<<<<<<< HEAD
Main branch changes
=======
Feature1 changes
>>>>>>> feature1
```

* Keep desired content manually

---

**Step 12: Add Resolved File**

```bash
git add file1.txt
```

---

**Step 13: Complete Merge**

```bash
git commit -m "Resolved merge conflict"
```

---

**Step 14: View Branches**

```bash
git branch
```

---

### **Result**

Successfully created branches, committed changes, merged branches, and resolved conflicts.
