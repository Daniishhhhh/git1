**EXPERIMENT 9: Jenkins Declarative Pipeline (Git + Maven) – Windows**

---

## 🎯 **Objective**

To create and execute a Jenkins Declarative Pipeline using a `Jenkinsfile` for building a Maven project.

---

## 🧭 **Startup Guide (Windows System)**

### **Step 0: Prerequisites**

* Jenkins running → `http://localhost:8080`
* Git installed and configured
* Maven installed and added to PATH
* GitHub repo with Maven project (`pom.xml` present)

---

## ⚙️ **Execution Steps**

---

# 🔹 **PART A: Create Jenkinsfile in Project**

### **Step 1: Go to Project Folder**

```bat id="r4t3ne"
cd C:\Users\danis\OneDrive\Desktop\maven-demo
```

---

### **Step 2: Create Jenkinsfile**

```bat id="l2mx3i"
notepad Jenkinsfile
```

👉 Add the following content:

```groovy id="5v9c5k"
pipeline {
    agent any

    stages {
        stage('Clone') {
            steps {
                echo 'Cloning repository...'
            }
        }

        stage('Build') {
            steps {
                bat 'mvn clean compile'
            }
        }

        stage('Test') {
            steps {
                bat 'mvn test'
            }
        }

        stage('Package') {
            steps {
                bat 'mvn package'
            }
        }
    }
}
```

---

### **Step 3: Push Jenkinsfile to GitHub**

```bat id="axwrde"
git add Jenkinsfile
git commit -m "Added Jenkins pipeline"
git push
```

---

# 🔹 **PART B: Create Pipeline Job in Jenkins**

### **Step 4: Create New Job**

* Click **New Item**
* Name: `pipeline-job`
* Select **Pipeline**
* Click **OK**

---

### **Step 5: Configure Pipeline**

* Scroll to **Pipeline Section**

👉 Definition:

```id="pl7vfm"
Pipeline script from SCM
```

👉 SCM:

```id="0hg4qn"
Git
```

👉 Repository URL:

```id="n9h4j6"
https://github.com/Daniishhhhh/maven-project.git
```

👉 Branch:

```id="7pt6y7"
*/main
```

👉 Script Path:

```id="z5s9k9"
Jenkinsfile
```

---

### **Step 6: Save Job**

* Click **Apply**
* Click **Save**

---

# 🔹 **PART C: Run Pipeline**

### **Step 7: Build the Pipeline**
