**EXPERIMENT 9: Jenkins Declarative Pipeline**

**Objective:**
To create and execute a Jenkins Declarative Pipeline using a Jenkinsfile.

---

### **Execution Steps**

### **Part A: Create Pipeline Job**

**Step 1: Open Jenkins Dashboard**

* Go to `http://localhost:8080`

---

**Step 2: Create New Item**

* Click **New Item**
* Enter name → `pipeline-job`
* Select **Pipeline**
* Click **OK**

---

### **Part B: Configure Pipeline**

**Step 3: Scroll to Pipeline Section**

* In **Pipeline → Definition**, select:
  **Pipeline script**

---

### **Part C: Add Jenkinsfile (Minimal Code)**

**Step 4: Enter Pipeline Script**

```groovy id="s9iqtf"
pipeline {
    agent any

    stages {
        stage('Build') {
            steps {
                echo 'Building project...'
            }
        }

        stage('Test') {
            steps {
                echo 'Running tests...'
            }
        }

        stage('Deploy') {
            steps {
                echo 'Deploying application...'
            }
        }
    }
}
```

---

### **Part D: Run Pipeline**

**Step 5: Save Job**

* Click **Save**

---

**Step 6: Build Pipeline**

* Click **Build Now**

---

### **Part E: View Output**

**Step 7: Check Console Output**

* Click build number → **Console Output**

---

**Step 8: View Pipeline Stages**

* Open **Stage View** to see Build → Test → Deploy flow

---

### **Result**

Successfully created and executed a Jenkins Declarative Pipeline with multiple stages.
