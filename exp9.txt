EXPERIMENT 9: RSA using OpenSSL + Audio Steganography (Python)
🎯 Short Description
Perform RSA key generation, encryption, and decryption using OpenSSL.
Hide and extract secret message inside an audio file using Python (LSB technique).
🔴 PART A: RSA using OpenSSL
⚙️ Step 1: Generate Private Key
openssl genrsa -out private.pem 2048
⚙️ Step 2: Generate Public Key
openssl rsa -in private.pem -pubout -out public.pem
⚙️ Step 3: Create Message File
notepad msg.txt

Write:

HELLO RSA
⚙️ Step 4: Encrypt Message
openssl rsautl -encrypt -inkey public.pem -pubin -in msg.txt -out msg.enc
⚙️ Step 5: Decrypt Message
openssl rsautl -decrypt -inkey private.pem -in msg.enc -out msg_dec.txt
⚙️ Step 6: View Output
notepad msg_dec.txt
✅ Result (Part A)

RSA encryption and decryption successfully performed using public and private keys.

🔴 PART B: Audio Steganography (Python – Input Based)
⚙️ Step 1: Keep Audio File
audio.wav
⚙️ Step 2: Create Python File
notepad audio_stego.py
⚙️ Step 3: Paste Code
import wave

# HIDE
def hide():
    audio_file = input("Enter audio file: ")
    msg = input("Enter message: ")

    msg += "#####"
    bits = ''.join(format(ord(c),'08b') for c in msg)

    song = wave.open(audio_file,'rb')
    frames = bytearray(song.readframes(song.getnframes()))
    params = song.getparams()
    song.close()

    index = 0
    for i in range(len(frames)):
        if index < len(bits):
            frames[i] = (frames[i] & ~1) | int(bits[index])
            index += 1
        else:
            break

    new_song = wave.open("stego.wav",'wb')
    new_song.setparams(params)
    new_song.writeframes(frames)
    new_song.close()

    print("Message hidden in stego.wav")


# EXTRACT
def extract():
    audio_file = input("Enter stego audio file: ")

    song = wave.open(audio_file,'rb')
    frames = bytearray(song.readframes(song.getnframes()))
    song.close()

    bits = ""
    for byte in frames:
        bits += str(byte & 1)

    msg = ""
    for i in range(0,len(bits),8):
        byte = bits[i:i+8]
        if len(byte) < 8:
            break

        char = chr(int(byte,2))
        msg += char

        if msg.endswith("#####"):
            print("Hidden Message:", msg[:-5])
            return

    print("No message found")


# MENU
print("1. Hide Message")
print("2. Extract Message")

choice = int(input("Enter choice: "))

if choice == 1:
    hide()
elif choice == 2:
    extract()
else:
    print("Invalid choice")
⚙️ Step 4: Run Program
python audio_stego.py
